# LIS AI — отдельный сайт

Готовый адаптивный сайт с тёмным интерфейсом, лисом-талисманом и неоново-зелёными акцентами. Чат работает через серверный API: секретный ключ не попадает в браузер.

## Запуск на компьютере
1. Установите Node.js 18 или новее.
2. Распакуйте архив и откройте терминал в папке проекта.
3. Выполните `npm install`.
4. Скопируйте `.env.example` в `.env` и вставьте свой API-ключ в `OPENAI_API_KEY`.
5. Запустите `npm start`.
6. Откройте `http://localhost:3000`.

## Публикация в интернете через Render
1. Загрузите файлы проекта в новый GitHub-репозиторий. Не загружайте `.env` и не публикуйте API-ключ.
2. В Render создайте новый Web Service и подключите репозиторий.
3. Build Command: `npm install`; Start Command: `npm start`.
4. В Environment Variables добавьте `OPENAI_API_KEY` как секрет и, при необходимости, `OPENAI_MODEL` со значением `gpt-4o-mini`.
5. После успешного deploy Render выдаст публичный адрес сайта.

## Важно
- Сам архив не означает, что сайт уже опубликован в интернете.
- Для AI-ответов нужен API-ключ с доступом и оплачиваемым балансом/лимитом у провайдера.
- Никогда не отправляйте API-ключ в чат и не коммитьте `.env`.
